## Pass criteria and limits

Read source contracts before choosing tools. Resolve workspace/teamspace IDs and
keep scope on operations that expose it. Keep generation/resource IDs distinct
from library asset UUIDs. Retain successes and resume pending work without blind
paid retries. Report unavailable deployed tools rather than pretending installation
exposes them. Creation/drafting does not authorize publishing.

Independent agent reviews used baseline existing instructions followed by the new
skill. The review found the baseline gaps above and checked the new guidance against
the same scenarios. This establishes documentation clarity and contract alignment,
not empirical agent tool execution or successful media downloads/renders. Live
OAuth I/O and visual checks remain separate validation before claiming runtime success.
